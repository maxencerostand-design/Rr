5

Coller les règles de sécurité

Firestore → onglet Rules

Ces règles font que chacun ne voit que ses propres données, uniquement connecté.

  1. Dans Firestore, onglet Rules / Règles
  2. Sélectionne tout, supprime, et colle le bloc ci-dessous
  3. Clique Publier
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /app_state/{uid} {
      allow read, write: if request.auth != null
        && request.auth.uid == uid;
    }
  }
}
🔒
Traduction : « autoriser lecture/écriture d'une fiche seulement si l'utilisateur est connecté et que la fiche lui appartient ». Sans ça, tout le monde pourrait lire tes données.

ℹ️
La apiKey n'est pas un mot de passe secret : c'est normal qu'elle soit dans le fichier. La vraie protection, c'est les règles (étape 5) + ton mot de passe (étape 7).

8

(Option) Mettre en ligne — accès téléphone

Firebase Hosting

Pour ouvrir l'app depuis ton téléphone via une adresse https://.

  1. Installe Node.js, puis dans un terminal les commandes ci-dessous
  2. Mets une copie du fichier renommée index.html dans un dossier vide
  3. Lance les commandes depuis ce dossier
npm install -g firebase-tools
firebase login
firebase init hosting     # projet existant · dossier public: .  · SPA: No · écraser index.html: No
firebase deploy           # → te donne https://mon-garage.web.app
📱
Ouvre l'URL …web.app sur ton téléphone, connecte-toi avec le même compte → tu retrouves toutes tes données. Pour republier après une modif : firebase deploy.
